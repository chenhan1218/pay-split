# Pay-Split - Project Index

## Vision

一個簡單、直覺的旅程與日常分帳 Web App，協助使用者輕鬆管理多人消費，自動計算債務關係。

## Documentation structure

- **Plans**
  - [Active Sprint](plans/active.md) - 當前執行中的任務
  - [Backlog](plans/backlog.md) - 未來規劃與靈感
- **Specifications (Specs)**
- [Specs: Core Data Model](specs/core_data_model.md) - 專案核心資料模型與功能規格

## Technical Architecture

- **Frontend Framework**: Next.js (React)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Context / Hooks (initially)
- **Storage**: LocalStorage (MVP), Database (Future)
